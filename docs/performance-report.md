# รายงานประสิทธิภาพในเครื่อง

วัดเมื่อ 2026-10-04 หลังเพิ่ม checklist และการโหลด subtasks แบบ batch ด้วย `npm run performance` โดยสร้าง SQLite ชั่วคราว 5,000 รายการ เปิด Express บนพอร์ตสุ่ม และเรียกผ่าน HTTP loopback หลัง warm-up 1 ครั้ง สถานการณ์ละ 20 requests ขนาดหน้าคงที่ 20 รายการ

## สภาพแวดล้อม

- Windows `win32 x64`
- Node.js `v24.18.0`
- SQLite จาก `node:sqlite`
- เครื่อง local ใน workspace นี้; ไม่มี network ภายนอกในเส้นทางที่วัด

## ผลที่วัดได้

| สถานการณ์ | ต่ำสุด | Median | P95 | สูงสุด |
| --- | ---: | ---: | ---: | ---: |
| รายการหน้าแรก เรียงล่าสุด | 1.14 ms | 12.36 ms | 18.25 ms | 18.39 ms |
| ค้นหาชื่อและกรอง `DONE` พร้อมกัน | 3.07 ms | 14.91 ms | 19.67 ms | 20.59 ms |

API ใช้ `LIMIT 20 OFFSET ...` จึงแบ่งหน้าที่ backend และโหลด tags/subtasks ของงาน 20 รายการด้วย batch query แยกอย่างละหนึ่งครั้งแทน N+1 query การค้นหา substring แบบ `%term%` ต้อง scan ชื่อบางส่วน; ที่ขนาดข้อมูลเป้าหมายยังไม่พบเหตุให้เพิ่ม cache หรือ search engine

ผลนี้ยืนยันเฉพาะ workload ผู้ใช้คนเดียวและ environment ข้างต้น ไม่ใช่หลักฐานรองรับผู้ใช้พร้อมกันจำนวนมากหรือ production traffic
